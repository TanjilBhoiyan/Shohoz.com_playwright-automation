Shohoz website Automation Testing script
This project contains end-to-end (E2E) automation tests for shohoz application using Playwright.

🚀 Installation , Setup and run test cases
Clone the repository
Navigate to the project folder
Install dependencies: npm install
Run playwright from the terminal: npx playwright test

📌 Features
Login functionality tests (Positive & Negative Scenarios)
Find the bus,air,Launch ticket schedule and can book bus ticket
Using page object model and Test data separation for better maintainability

🛠️ Tech Stack
Language: JavaScript
Test Framework: Playwright
Package Manager: npm
Version Control: Git
